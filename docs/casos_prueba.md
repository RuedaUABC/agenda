# Casos de Prueba

Este documento consolida los test cases de las funcionalidades de Agenda usando
el formato solicitado. Los casos marcados como `Pass` tienen cobertura
automatizada o evidencia funcional implementada; los casos `Partial` describen
funcionalidad implementada con brechas conocidas; los casos `Not Executed`
documentan pruebas manuales pendientes para requisitos sugeridos o sin cobertura
automatizada especifica.
